  <name>Task 1: Build <HeroBackdrop> dispatcher with phase state machine</name>
  <files>src/components/plasma/HeroBackdrop.tsx</files>
  <action>
    Create `src/components/plasma/HeroBackdrop.tsx`. This is THE dispatcher — it reads device capabilities, drives the ScrollTrigger-based mount decision, and runs the pre-unmount fade. Follow RESEARCH.md §"Pattern 3" (ScrollTrigger-driven boolean) + §"Pattern 4" (pre-unmount fade) + §"Full HeroBackdrop dispatcher skeleton" — use the skeleton there as the starting point.

    1. **Imports**:
       - `useRef`, `useState`, `type RefObject` from `'react'`
       - `gsap`, `ScrollTrigger`, `useGSAP` from `'@/lib/gsap'` — NEVER from `'gsap'` directly (Phase 1 rule, see STATE.md decisions)
       - `useDeviceCapabilities` from `'@/hooks/useDeviceCapabilities'`
       - `Plasma` from `'./Plasma'`
       - `PlasmaFallback` from `'./PlasmaFallback'`
       Note: `gsap` is imported but may be unused in this file — that's fine, the registration side-effect is what matters. Actually, you can omit `gsap` from the import if not referenced; only `ScrollTrigger` and `useGSAP` are needed here.

    2. **Props**:
       ```ts
       interface HeroBackdropProps {
         heroRef: RefObject<HTMLElement | null>
       }
       ```
       The ref-null tolerance (`HTMLElement | null`) matches React 19's `useRef<HTMLElement>(null)` inferred type. The dispatcher must handle `heroRef.current === null` gracefully — see step 5 below.

    3. **Constants**:
       ```ts
       const FADE_MS = 250
       ```
       Per CONTEXT.md "200–300ms opacity fade before React unmounts the component." 250 lands in the middle.

    4. **State + refs**:
       ```ts
       const { prefersReducedMotion, isMobile, supportsWebGL2 } = useDeviceCapabilities()
       const useFallback = prefersReducedMotion || !supportsWebGL2
       const [phase, setPhase] = useState<'visible' | 'fading' | 'unmounted'>('visible')
       const fadeTimerRef = useRef<number | null>(null)
       const containerRef = useRef<HTMLDivElement>(null)
       ```
       `isLowEnd` is NOT in the fallback trigger — CONTEXT.md says fallback fires on `prefersReducedMotion || !supportsWebGL2`. Low-end devices that DO have WebGL2 still get the real Plasma at the capped DPR. The low-end signal is reserved for finer-grained Phase 7 tuning.

    5. **`useGSAP` block** — owns the ScrollTrigger that drives the phase transitions:

       ```tsx
       useGSAP(
         () => {
           if (useFallback) return            // fallback path never unmounts on scroll
           if (!heroRef.current) return       // ref not yet attached — bail; useGSAP re-runs via dependencies

           const trigger = ScrollTrigger.create({
             trigger: heroRef.current,
             start: 'top top',                // hero top hits viewport top
             end: 'bottom top',               // hero bottom fully leaves viewport (100% past — CONTEXT-locked)
             onLeave: () => {
               setPhase('fading')
               if (fadeTimerRef.current) window.clearTimeout(fadeTimerRef.current)
               fadeTimerRef.current = window.setTimeout(() => {
                 setPhase('unmounted')
                 fadeTimerRef.current = null
               }, FADE_MS)
             },
             onEnterBack: () => {
               // Cancel any pending fade timer — user scrolled back before it fired
               if (fadeTimerRef.current) {
                 window.clearTimeout(fadeTimerRef.current)
                 fadeTimerRef.current = null
               }
               setPhase('visible')
             },
           })

           return () => {
             if (fadeTimerRef.current) {
               window.clearTimeout(fadeTimerRef.current)
               fadeTimerRef.current = null
             }
             trigger.kill()
           }
         },
         { scope: containerRef, dependencies: [heroRef, useFallback] }
       )
       ```

       Critical details:
       - `scope: containerRef` (NOT `heroRef`) — `useGSAP` uses scope for its OWN cleanup; the ScrollTrigger's `trigger` config is the hero element. See RESEARCH §"Full <HeroBackdrop> dispatcher skeleton" note.
       - `dependencies: [heroRef, useFallback]` — when `useFallback` flips (OS reduced-motion toggled mid-session, addressed in research Open Question 1), the ScrollTrigger is torn down. When `heroRef.current` populates after first paint (Pitfall 5), the effect re-runs.
       - The cleanup kills `trigger` specifically — NEVER `ScrollTrigger.getAll().forEach(t => t.kill())`. That would also kill the Phase 3 RevealSection / ParallaxCard triggers still living in the test harness (RESEARCH §Anti-Patterns).
       - `onLeave` clears any stale fade timer before scheduling a new one (defensive — prevents a leaked timer if the user scrolls past, back, and past again within 250ms).

    6. **Render** — three branches:

       a. **Fallback path** (never creates GL, never unmounts):
          ```tsx
          if (useFallback) {
            return (
              <div
                ref={containerRef}
                style={{ position: 'absolute', inset: 0, pointerEvents: 'none' }}
              >
                <PlasmaFallback animated={!prefersReducedMotion} />
              </div>
            )
          }
          ```
          The `animated` prop is true when `!prefersReducedMotion` (i.e., the user wants motion but the GL path is unavailable — low-end / no-WebGL2). Static when `prefersReducedMotion` (per CONTEXT.md).

       b. **Unmounted state** — keep the ref-host div mounted so `containerRef.current` stays non-null and the `useGSAP` scope-bound cleanup stays valid for `onEnterBack`:
          ```tsx
          if (phase === 'unmounted') {
            return (
              <div
                ref={containerRef}
                style={{ position: 'absolute', inset: 0, pointerEvents: 'none' }}
                aria-hidden="true"
              />
            )
          }
          ```
          NOTE: This branch renders an EMPTY container — no `<Plasma>` child. That is the "WebGL context truly released" state.

       c. **Visible or fading** — render `<Plasma>` inside the fading-opacity wrapper:
          ```tsx
          return (
            <div
              ref={containerRef}
              style={{
                position: 'absolute',
                inset: 0,
                opacity: phase === 'fading' ? 0 : 1,
                transition: `opacity ${FADE_MS}ms ease-out`,
                pointerEvents: 'none',
              }}
              aria-hidden="true"
            >
              <Plasma
                color="#FF4500"
                speed={0.35}
                direction="forward"
                scale={1.1}
                opacity={0.85}
                mouseInteractive={!isMobile}
              />
            </div>
          )
          ```
          ALL `<Plasma>` props are stable primitives — no inline objects, no computed values, no `useMemo` needed. The `useEffect` in `<Plasma>` will only fire on real mount/unmount (RESEARCH §"Pattern 5"). `mouseInteractive={!isMobile}` per CONTEXT.md.

    7. **Export**: `export function HeroBackdrop({ heroRef }: HeroBackdropProps) { ... }`.

    8. **TypeScript strict**: file must `npm run build` with no errors. `npm run lint` must pass.

    Anti-patterns to AVOID:
    - DO NOT call `ScrollTrigger.getAll()` anywhere — kills other components' triggers.
    - DO NOT use `IntersectionObserver` — the codebase uses ScrollTrigger as the single source of truth.
    - DO NOT bypass `useGSAP` — its scope-bound cleanup is what makes the ScrollTrigger get killed when `<HeroBackdrop>` unmounts.
    - DO NOT subscribe to `scrollStore` here — RESEARCH §"Pattern 3" recommends ScrollTrigger callbacks, scrollStore has zero consumers yet.
    - DO NOT pass inline objects/functions to `<Plasma>` — would re-init GL on every render (RESEARCH §"Pattern 5").
  </action>

<task type="auto">
  <name>Task 2: Create ScrollContext with ref-based external store and rAF coalescing</name>
  <files>src/context/ScrollContext.tsx</files>
  <action>
    Create src/context/ScrollContext.tsx implementing the ref-based external store pattern.

    Module-level mutable state (NOT React state):
    - `let scrollY = 0` — updated on every rAF callback
    - `let scrollProgress = 0` — scrollY / (scrollHeight - clientHeight), clamped to 0–1
    - `const listeners = new Set<() => void>()` — subscriber set

    Helper: `function computeProgress(): number` — reads document.documentElement scrollHeight and clientHeight, returns scrollY divided by scrollable height (guard for scrollable === 0).

    External store object `scrollStore`:
    - `subscribe(callback: () => void): () => void` — adds to listeners Set, returns unsubscribe function that calls listeners.delete(callback)
    - `getSnapshot(): { y: number; progress: number }` — returns { y: scrollY, progress: scrollProgress }
    - `getRef(): { y: number; progress: number }` — same as getSnapshot, used by GSAP components reading directly without React subscription

    ScrollContext: `createContext<{ subscribe; getSnapshot } | null>(null)` — the value shape matches scrollStore.

    ScrollProvider component:
    - Uses `const rafRef = useRef<number | null>(null)`
    - useEffect that:
      1. Defines onScroll: if rafRef.current !== null, cancelAnimationFrame(rafRef.current). Then requestAnimationFrame(() => { scrollY = window.scrollY; scrollProgress = computeProgress(); listeners.forEach(cb => cb()); rafRef.current = null })
      2. Calls window.addEventListener('scroll', onScroll, { passive: true })
      3. Returns cleanup: window.removeEventListener('scroll', onScroll), and if rafRef.current !== null then cancelAnimationFrame(rafRef.current)
    - Returns <ScrollContext.Provider value={scrollStore}>{children}</ScrollContext.Provider>

    useScrollContext() hook:
    - const ctx = useContext(ScrollContext)
    - if (!ctx) throw new Error('useScrollContext must be used within ScrollProvider')
    - return ctx

    Export: ScrollProvider (named), useScrollContext (named), scrollStore (named)

    TypeScript: Add ScrollSnapshot interface { y: number; progress: number } and export it for consumer typing.

    DO NOT use useState anywhere in this file — scroll position must never go through React reconciliation.
  </action>

  </verify>

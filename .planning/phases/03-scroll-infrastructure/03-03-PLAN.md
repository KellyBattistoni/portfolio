  <files>src/main.tsx, src/App.tsx</files>
  <action>
    **src/main.tsx changes:**
    Import ScrollProvider from '@/context/ScrollContext'.
    Wrap the <App /> render with <ScrollProvider>:
      <StrictMode>
        <ScrollProvider>
          <App />
        </ScrollProvider>
      </StrictMode>

    **src/App.tsx additions:**
    At the top of the App function body, add a useEffect (after existing hooks) that calls:
      document.fonts.ready.then(() => {
        ScrollTrigger.refresh()
      })
    Import ScrollTrigger from '@/lib/gsap'.
    Import useEffect from 'react' (add to existing import if already present).

    This fixes a known issue: Playfair Display loads asynchronously from Google Fonts. If ScrollTrigger calculates element positions before the font is loaded, it may compute wrong trigger offsets because Playfair Display has different metrics than the fallback font, changing layout height. Calling ScrollTrigger.refresh() after document.fonts.ready forces a recalculation.

    Add the test harness (described in Task 2) in the same App.tsx edit — but this task covers only the ScrollProvider wrap and font refresh.

    IMPORTANT: Do NOT modify the existing demo hero section — it must remain unchanged per CONTEXT.md (Phase 5 will replace the whole hero, not Phase 3).
  </action>

  </verify>

  </done>

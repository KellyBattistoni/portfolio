  <action>
    Create src/components/scroll/RevealSection.tsx.

    Create the scroll/ subdirectory if it doesn't exist.

    Export type RevealVariant = 'fade-up' | 'slide-from-left' | 'scale-up'

    VARIANTS record mapping each variant to { from: gsap.TweenVars, to: gsap.TweenVars }:
    - fade-up: from { opacity: 0, y: 30 }, to { opacity: 1, y: 0 }
    - slide-from-left: from { opacity: 0, x: -50 }, to { opacity: 1, x: 0 }
    - scale-up: from { opacity: 0, scale: 0.92 }, to { opacity: 1, scale: 1 }

    Props interface RevealSectionProps:
    - children: ReactNode
    - variant?: RevealVariant (default: 'fade-up')
    - stagger?: boolean (default: true)
    - duration?: number (default: 0.6 — within the 500–700ms range specified)
    - delay?: number (optional per-section offset)
    - className?: string

    Component body:
    1. const containerRef = useRef<HTMLDivElement>(null)
    2. const { prefersReducedMotion } = useDeviceCapabilities()
    3. useGSAP (imported from '@/lib/gsap') with { scope: containerRef, dependencies: [variant, stagger, duration, prefersReducedMotion] }:
       - If prefersReducedMotion is true: return immediately (children render as-is, no animation)
       - Create mm = gsap.matchMedia()
       - mm.add('(prefers-reduced-motion: no-preference)', () => {
           const { from, to } = VARIANTS[variant]
           const childEls = containerRef.current ? Array.from(containerRef.current.children) : []
           if (stagger && childEls.length > 1):
             gsap.fromTo(childEls, from, { ...to, duration, ease: 'power2.out', stagger: 0.12, delay: delay ?? 0, scrollTrigger: { trigger: containerRef.current, start: 'top 85%', once: true } })
           else:
             gsap.fromTo(containerRef.current, from, { ...to, duration, ease: 'power2.out', delay: delay ?? 0, scrollTrigger: { trigger: containerRef.current, start: 'top 85%', once: true } })
           return () => ScrollTrigger.getAll().forEach(t => t.kill())
         })
       - return () => mm.revert()
    4. Return <div ref={containerRef} className={className}>{children}</div>

    Import useGSAP from '@/lib/gsap' (not from '@gsap/react' directly — use the centralized module).
    Import gsap and ScrollTrigger from '@/lib/gsap'.
    Import useDeviceCapabilities from '@/hooks/useDeviceCapabilities'.
    Import useRef, ReactNode from 'react'.

    IMPORTANT: ease: 'power2.out' maps to ease-out-cubic behavior (GSAP power2 is cubic) — matches the "smooth and cinematic" requirement.

<task type="auto">
  <name>Task 2: Build ParallaxCard with GSAP ticker + quickSetter multi-layer API</name>
  <files>src/components/scroll/ParallaxCard.tsx</files>
  <action>
    Create src/components/scroll/ParallaxCard.tsx.

    Export interface ParallaxLayer:
    - content: ReactNode
    - speed: number  — multiplier: 0 = static, 0.2 = moves 20px per 100px scroll, negative = counter-parallax
    - className?: string

    Export interface ParallaxCardProps:
    - layers: ParallaxLayer[]
    - className?: string

    Component body:
    1. const cardRef = useRef<HTMLDivElement>(null)
    2. const layerRefs = useRef<(HTMLDivElement | null)[]>([])
    3. const { prefersReducedMotion, isMobile } = useDeviceCapabilities()
    4. useGSAP (from '@/lib/gsap') with { scope: cardRef, dependencies: [prefersReducedMotion, isMobile] }:
       - If prefersReducedMotion || isMobile: return (skip parallax)
       - Create quickSetters: const setters = layers.map((_, i) => { const el = layerRefs.current[i]; return el ? gsap.quickSetter(el, 'y', 'px') : null })
       - let lastScrollY = scrollStore.getRef().y
       - Define tick function:
           const currentY = scrollStore.getRef().y
           const delta = currentY - lastScrollY
           layers.forEach((layer, i) => {
             const setter = setters[i]
             if (!setter) return
             const el = layerRefs.current[i]
             if (!el) return
             const current = gsap.getProperty(el, 'y') as number
             setter(current + delta * layer.speed)
           })
           lastScrollY = currentY
       - gsap.ticker.add(tick)
       - return () => gsap.ticker.remove(tick)
    5. Return:
       <div ref={cardRef} className={className} style={{ position: 'relative', overflow: 'hidden' }}>
         {layers.map((layer, i) => (
           <div key={i} ref={(el) => { layerRefs.current[i] = el }} className={layer.className} style={{ position: 'absolute', inset: 0 }}>
             {layer.content}
           </div>
         ))}
       </div>

    Imports:
    - useRef, ReactNode from 'react'
    - useGSAP, gsap from '@/lib/gsap'
    - scrollStore from '@/context/ScrollContext'
    - useDeviceCapabilities from '@/hooks/useDeviceCapabilities'

    overflow: hidden on the card container is LOCKED per user decision — content movement stays clipped within the frame.
    Do NOT add window.addEventListener('scroll') anywhere in this file — all scroll reads go through scrollStore.getRef() in the ticker.
  </action>

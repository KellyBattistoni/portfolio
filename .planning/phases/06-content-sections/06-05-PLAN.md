Implementation specifics:

```tsx
import { useState } from 'react'
import { useTranslation } from 'react-i18next'
import { RevealSection } from '@/components/scroll/RevealSection'

export function Contact() {
  const { t } = useTranslation('contact')
  const [cvLang, setCvLang] = useState<'en' | 'es'>('en')
  const cvHref = cvLang === 'en'
    ? '/Harvard_CV_Kelly_Battistoni_EN.pdf'
    : '/Harvard_CV_Kelly_Battistoni_ES.pdf'

  return (
    <section id="contact" aria-label={t('heading')} style={{ padding: '6rem 1.5rem', maxWidth: '52rem', margin: '0 auto' }}>
      <RevealSection stagger>
        <h2 style={{ fontFamily: 'var(--font-display)', ... }}>{t('heading')}</h2>
        <p style={{ ... }}>{t('invite')}</p>
        <div style={{ display: 'flex', gap: '1.5rem', flexWrap: 'wrap', marginTop: '2rem' }}>
          <a href="mailto:kelly@seomarketing.com" style={{ ... }}>{t('email.label')}</a>
          <a href={t('linkedin.url')} target="_blank" rel="noopener noreferrer" style={{ ... }}>{t('linkedin.label')}</a>
        </div>
        <div role="group" aria-labelledby="cv-group-label" style={{ marginTop: '3rem' }}>
          <p id="cv-group-label" style={{ ... }}>{t('cv.label')}</p>
          <div role="radiogroup" aria-label={t('cv.label')} style={{ display: 'flex', gap: '0.5rem' }}>
            <button type="button" role="radio" aria-checked={cvLang === 'en'} onClick={() => setCvLang('en')}>{t('cv.toggle.en')}</button>
            <button type="button" role="radio" aria-checked={cvLang === 'es'} onClick={() => setCvLang('es')}>{t('cv.toggle.es')}</button>
          </div>
          <a href={cvHref} download style={{ display: 'inline-block', marginTop: '1rem', border: '1px solid var(--color-brand-accent)', padding: '0.875rem 2.25rem', textDecoration: 'none', color: 'inherit' }}>
            {t('cv.download')}
          </a>
        </div>
      </RevealSection>
    </section>
  )
}
```

Critical rules (locked decisions + research):

1. `cvHref` derives from the LOCAL `cvLang` useState, NEVER from `i18n.language`. Research Pitfall 3 documents this — if you wire `cvHref` to the i18n language, browsing in EN forces an EN download even if the user explicitly clicked the ES toggle. The whole point of the toggle is independence from site language.

2. mailto literal: `mailto:kelly@seomarketing.com` — hardcoded in the JSX, NOT translated. The visible label `{t('email.label')}` IS the email address, displayed for the user.

3. LinkedIn: `href={t('linkedin.url')}` — read from i18n so swapping the placeholder doesn't require a code edit later. `target="_blank"` + `rel="noopener noreferrer"` — explicit even though modern browsers auto-imply `noopener` (defense-in-depth, silences `eslint-plugin-react/jsx-no-target-blank`).

4. `download` attribute on the CV anchor is BARE (no value) so the browser preserves the original filename `Harvard_CV_Kelly_Battistoni_EN.pdf` / `..._ES.pdf` from the URL path.

5. CV toggle is two `<button role="radio">` elements wrapped in a `role="radiogroup"`. NOT a real `<input type="radio">` — the toggle controls download state, not form submission. `aria-checked` reflects current state.

6. Direct children of `RevealSection` (h2, p, div, div) DO satisfy the stagger-direct-children rule. Each gets its own stagger step. Acceptable.

7. Reduced motion: covered by `RevealSection`'s built-in `prefersReducedMotion` early-return + matchMedia teardown. No additional guards needed.

DO NOT add a form library. DO NOT add a Calendly / meeting-scheduler embed (deferred per CONTEXT.md). DO NOT use JS-fetch-blob for the PDF download — the `<a href download>` pattern is the standard (research Don't Hand-Roll table).

DO NOT use `<a href={emailAddress}>` with a separate `emailAddress` variable. The literal `mailto:` href is clearer and matches the visible label.

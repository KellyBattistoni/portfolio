  <name>Task 2: Create ProjectCard.tsx — ParallaxCard wraps ONLY the card face; details panel is a normal-flow sibling outside</name>

  <action>
Create `src/components/sections/ProjectCard.tsx` exporting `ProjectCard`. Pattern follows Pattern 3 in 06-RESEARCH.md with one CRITICAL architectural correction (see Architecture note below).

Key API:

```tsx
interface ProjectCardProps {
  projectId: 'project1' | 'project2' | 'project3' | 'project4'
  parallaxSpeed: number
}
export function ProjectCard({ projectId, parallaxSpeed }: ProjectCardProps) { ... }
```

ARCHITECTURE — Read this first, it overrides any prior pattern guidance:

`ParallaxCard` renders its `layers` prop as `<div style={{ position: 'absolute', inset: 0 }}>` children inside a container with `overflow: hidden`. That means anything placed inside a ParallaxCard layer is pinned to the card's initial height — a `max-height: 0 → 600px` transition on a child of the layer has NO room to grow and the overflow is clipped at the card edge.

To make the expand-in-place feature actually work, the ProjectCard must be restructured so that:
- An OUTER wrapper `<div style={{ position: 'relative' }}>` contains BOTH the `<ParallaxCard>` AND the collapsible details panel.
- ONLY the card face (the `<button>` with title + context + outcome + tech tags) lives inside the `<ParallaxCard>` as a single layer.
- The collapsible details panel is a normal-flow sibling AFTER the `<ParallaxCard>` element, inside the outer wrapper. It can expand freely in document flow without fighting `overflow: hidden`.

Required component shape:

```tsx
import { useState, useId } from 'react'
import { useTranslation } from 'react-i18next'
import { ParallaxCard } from '@/components/scroll/ParallaxCard'
import { useDeviceCapabilities } from '@/hooks/useDeviceCapabilities' // path may differ — match existing hook location

interface ProjectCardProps {
  projectId: 'project1' | 'project2' | 'project3' | 'project4'
  parallaxSpeed: number
}

export function ProjectCard({ projectId, parallaxSpeed }: ProjectCardProps) {
  const { t } = useTranslation('projects')
  const [expanded, setExpanded] = useState(false)
  const detailsId = useId()
  const { prefersReducedMotion } = useDeviceCapabilities()
  const tech = t(`cards.${projectId}.tech`, { returnObjects: true }) as string[]

  return (
    <div style={{ position: 'relative' }}>
      <ParallaxCard
        layers={[{
          speed: parallaxSpeed,
          content: (
            <button
              type="button"
              onClick={() => setExpanded((v) => !v)}
              aria-expanded={expanded}
              aria-controls={detailsId}
              aria-label={`${t(`cards.${projectId}.title`)} — ${expanded ? t('labels.collapse') : t('labels.expand')}`}
              style={{
                width: '100%',
                height: '100%',
                background: 'transparent',
                border: 'none',
                color: 'inherit',
                padding: '2rem',
                textAlign: 'left',
                cursor: 'pointer',
                display: 'flex',
                flexDirection: 'column',
                gap: '0.75rem',
              }}
            >
              <h3 style={{ fontFamily: 'var(--font-display)' }}>{t(`cards.${projectId}.title`)}</h3>
              <p>{t(`cards.${projectId}.context`)}</p>
              <p style={{ color: 'var(--color-brand-accent)' }}>{t(`cards.${projectId}.outcome`)}</p>
              <ul aria-label={t('labels.tech')} style={{ display: 'flex', flexWrap: 'wrap', gap: '0.5rem', listStyle: 'none', padding: 0, margin: 0 }}>
                {tech.map((tag) => (
                  <li key={tag} style={{ padding: '0.25rem 0.5rem', border: '1px solid var(--color-brand-accent)', borderRadius: 999, fontSize: '0.75rem', opacity: 0.85 }}>{tag}</li>
                ))}
              </ul>
            </button>
          ),
        }]}
        // The ParallaxCard wrapper gives the card face a fixed height to scrub against.
        // It contains ONLY the card face — the details panel is below in normal flow.
        style={{
          minHeight: '260px',
          background: 'var(--color-brand-card)',
          border: '1px solid rgba(255,255,255,0.1)',
          borderRadius: 12,
        }}
      />
      {/* Details panel — normal-flow sibling OUTSIDE ParallaxCard, expands freely */}
      <div
        id={detailsId}
        aria-hidden={!expanded}
        style={{
          maxHeight: expanded ? '600px' : 0,
          opacity: expanded ? 1 : 0,
          overflow: 'hidden',
          transition: prefersReducedMotion ? 'none' : 'max-height 0.4s ease, opacity 0.3s ease',
          background: 'var(--color-brand-card)',
          borderLeft: '1px solid rgba(255,255,255,0.1)',
          borderRight: '1px solid rgba(255,255,255,0.1)',
          borderBottom: '1px solid rgba(255,255,255,0.1)',
          borderRadius: '0 0 12px 12px',
          marginTop: '-1px', // join visually under the card face
          padding: expanded ? '1.5rem 2rem 2rem' : '0 2rem',
        }}
      >
        <h4>{t('labels.problem')}</h4>
        <p>{t(`cards.${projectId}.problem`)}</p>
        <h4>{t('labels.solution')}</h4>
        <p>{t(`cards.${projectId}.solution`)}</p>
        <h4>{t('labels.result')}</h4>
        <p>{t(`cards.${projectId}.result`)}</p>
      </div>
    </div>
  )
}
```

Implementation rules (all derived from locked decisions, research, and STATE memory):

1. **CRITICAL: Details panel MUST be a sibling of ParallaxCard, NOT a child of any ParallaxCard layer.** See Architecture note above. Putting the collapsible div inside a ParallaxCard layer (position:absolute;inset:0;overflow:hidden parent) silently breaks the expand-in-place feature — the layer is pinned to the card's height and overflow is clipped.

2. State the expand toggle in plain `useState<boolean>(false)` — NOT inside `useGSAP` and NOT passed as a `useGSAP` dependency. Research / STATE [05-03] documents that state-in-useGSAP-deps rebuilds timelines on toggle. The expand-in-place animation is CSS-only (`max-height` + `opacity` transitions).

3. Accessibility:
   - The clickable face is a `<button type="button">` (NOT a div with onClick). Keyboard focusable, screen-reader friendly.
   - Use `useId()` for the details panel id. Set `aria-expanded={expanded}` and `aria-controls={detailsId}` on the button, `id={detailsId}` on the details panel.
   - Button `aria-label` includes the current toggle state hint so screen readers announce the change.

4. ParallaxCard wraps ONLY the card face. A single layer with `speed: parallaxSpeed`. (Multi-layer depth is overkill for case-study cards; one drifting layer is what the spec wants.) Card-face minHeight: 260px (gives the ParallaxCard a defined height to scrub against — the details panel grows below in normal flow, so the outer card no longer needs the old 420px ceiling).

5. Card face content order (inside the ParallaxCard layer's `<button>`):
   - `<h3>` with `t('cards.' + projectId + '.title')` (font-display)
   - `<p>` with `t('cards.' + projectId + '.context')`
   - `<p>` with `t('cards.' + projectId + '.outcome')` styled with brand-accent color (`color: var(--color-brand-accent)`)
   - Tech tags as a horizontal flex list: `<ul aria-label={t('labels.tech')}>` with `<li>` per tag. Read tech with `const tech = t(`cards.${projectId}.tech`, { returnObjects: true }) as string[]`. Each `<li>` is a small pill.

6. Collapsible details panel (outside ParallaxCard, in the outer relative div):
   - `<div id={detailsId} aria-hidden={!expanded} style={{ maxHeight: expanded ? '600px' : 0, opacity: expanded ? 1 : 0, overflow: 'hidden', transition: ... }}>`
   - Contents: three labeled blocks (problem/solution/result), each `<h4>` + `<p>` pair, copy from `t(`cards.${projectId}.{problem|solution|result}`)`.
   - Visual continuity: same background as the card face (`var(--color-brand-card)`), matching side+bottom borders, rounded only on the bottom corners so the panel reads as the card "growing" downward. Set `marginTop: '-1px'` to join cleanly under the face.

7. Reduced motion: use the existing `useDeviceCapabilities()` hook (same one used by HeroBackdrop and other components) — when `prefersReducedMotion === true`, set `transition: 'none'` so the toggle is instant.

8. Card visual styling: background `var(--color-brand-card)`, border `1px solid rgba(255,255,255,0.1)`, border-radius 12px, button padding 2rem.

9. Per research Pitfall 4 / STATE memory: mobile ParallaxCard skips the parallax tween — the card face content renders at its untransformed position on mobile (still visible). The outside-of-ParallaxCard details panel obviously also renders fine on mobile (no parallax involved).

DO NOT place the collapsible details div inside the ParallaxCard `layers` array. DO NOT place it inside the `<button>` (a button cannot contain block flow content like multiple `<h4>` siblings, and it would still be inside the absolute-positioned layer). Place it as a sibling of `<ParallaxCard>` inside the outer wrapper `<div style={{ position: 'relative' }}>`.

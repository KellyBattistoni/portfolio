<task type="auto">
  <name>Task 2: Create ProjectCard.tsx with ParallaxCard wrapper + expand-in-place state</name>
  <files>src/components/sections/ProjectCard.tsx</files>
  <action>
Create `src/components/sections/ProjectCard.tsx` exporting `ProjectCard`. Pattern follows Pattern 3 in 06-RESEARCH.md exactly.

Key API:

```tsx
interface ProjectCardProps {
  projectId: 'project1' | 'project2' | 'project3' | 'project4'
  parallaxSpeed: number
}
export function ProjectCard({ projectId, parallaxSpeed }: ProjectCardProps) { ... }
```

Implementation rules (all derived from locked decisions, research, and STATE memory):

1. State the expand toggle in plain `useState<boolean>(false)` — NOT inside `useGSAP` and NOT passed as a `useGSAP` dependency. Research / STATE [05-03] documents that state-in-useGSAP-deps rebuilds timelines on toggle. The expand-in-place animation is CSS-only (`max-height` + `opacity` transitions).

2. Accessibility:
   - The clickable face is a `<button type="button">` (NOT a div with onClick). Keyboard focusable, screen-reader friendly.
   - Use `useId()` for the details panel id. Set `aria-expanded={expanded}` and `aria-controls={detailsId}` on the button, `id={detailsId}` on the details panel.
   - Button label includes `aria-label={`${t('cards.' + projectId + '.title')} — ${expanded ? t('labels.collapse') : t('labels.expand')}`}` so screen readers know the toggle state changed.

3. ParallaxCard wraps the whole card. Use a SINGLE layer with `speed: parallaxSpeed`. (Multi-layer depth is overkill for case-study cards; one drifting layer is what the spec wants.) The layer's content IS the entire card face (button + collapsed-details div together).

4. Card face content order:
   - `<h3>` with `t('cards.' + projectId + '.title')` (font-display)
   - `<p>` with `t('cards.' + projectId + '.context')`
   - `<p>` with `t('cards.' + projectId + '.outcome')` styled with brand-accent color (`color: var(--color-brand-accent)`)
   - Tech tags as a horizontal flex list: `<ul aria-label={t('labels.tech')}>` with `<li>` per tag. Read tech with `const tech = t(`cards.${projectId}.tech`, { returnObjects: true }) as string[]`. Each `<li>` is a small pill (`padding: 0.25rem 0.5rem; border: 1px solid var(--color-brand-accent); border-radius: 999px; font-size: 0.75rem; opacity: 0.85`).

5. Collapsible details panel (below the button, inside the same ParallaxCard layer):
   - `<div id={detailsId} style={{ maxHeight: expanded ? '600px' : 0, opacity: expanded ? 1 : 0, overflow: 'hidden', transition: 'max-height 0.4s ease, opacity 0.3s ease' }}>`
   - Contents: three labeled blocks
     - `<h4>{t('labels.problem')}</h4><p>{t(`cards.${projectId}.problem`)}</p>`
     - `<h4>{t('labels.solution')}</h4><p>{t(`cards.${projectId}.solution`)}</p>`
     - `<h4>{t('labels.result')}</h4><p>{t(`cards.${projectId}.result`)}</p>`
   - When `expanded` is false the panel is `aria-hidden="true"` (and the parent's `aria-expanded="false"` already signals state).

6. Reduced motion: the CSS transition is short and only on `max-height` + `opacity`. Respect `prefers-reduced-motion` via a CSS media query — wrap the `transition` value in a guard so reduced-motion users get instant toggle:
   - Apply `transition: 'none'` via `useDeviceCapabilities().prefersReducedMotion` (re-use the existing hook) — when true, drop the transition entirely.

7. Card visual styling (Tailwind classes via clsx or inline):
   - Background: `var(--color-brand-card)` (already exposed in `@theme`).
   - Border: 1px solid rgba(255,255,255,0.1).
   - Border radius: ~12px.
   - Padding inside the layer: 2rem.
   - Cursor on the button: pointer; no border; transparent background; inherit color.

8. ParallaxCard's `overflow: hidden` clips at the card edge (locked decision per STATE [03-02]). Make sure the collapsible details panel does NOT need to overflow — the 600px maxHeight ceiling is enough for the planned copy lengths; the panel grows the card height naturally inside the clip.

IMPORTANT: Per research Pitfall 4, mobile ParallaxCard skips the parallax tween — so the card face content lives at speed=parallaxSpeed and renders at its untransformed position on mobile (still visible). Do NOT split content across multiple layers with non-zero speeds in a way that depends on transform to be in-bounds.

<task type="auto">
  <name>Task 2: Create About.tsx section component with RevealSection + brand-accent divider</name>
  <files>src/components/sections/About.tsx</files>
  <action>
Create the directory `src/components/sections/` if it does not exist. Create `About.tsx` exporting a named `About` function component:

```tsx
import { useTranslation } from 'react-i18next'
import { RevealSection } from '@/components/scroll/RevealSection'

export function About() {
  const { t } = useTranslation('about')
  return (
    <section id="about" aria-label={t('title')} style={{ padding: '6rem 1.5rem', maxWidth: '52rem', margin: '0 auto' }}>
      <RevealSection stagger>
        <span aria-hidden="true" style={{ display: 'block', height: '1px', width: '3rem', background: 'var(--color-brand-accent)', marginBottom: '1.5rem' }} />
        <h2 style={{ fontFamily: 'var(--font-display)', fontSize: 'clamp(2rem, 5vw, 3rem)', marginTop: 0, marginBottom: '2rem' }}>{t('title')}</h2>
        <p style={{ fontSize: '1.125rem', lineHeight: 1.7, marginBottom: '1.5rem' }}>{t('paragraph1')}</p>
        <p style={{ fontSize: '1.125rem', lineHeight: 1.7, marginBottom: '1.5rem' }}>{t('paragraph2')}</p>
        <p style={{ fontSize: '1.125rem', lineHeight: 1.7, marginBottom: 0 }}>{t('paragraph3')}</p>
      </RevealSection>
    </section>
  )
}
```

Specifics that MUST be honored:
- `id="about"` — matches the `#about` anchor PillNav already links to (`common.nav.about`).
- The decorative `<span>` divider satisfies CONTEXT.md locked decision "one subtle design element" (thin 1px × 3rem horizontal bar in `--color-brand-accent`). `aria-hidden="true"` keeps screen readers focused on the prose.
- The `<span>`, `<h2>`, and three `<p>` elements are ALL DIRECT children of `<RevealSection>` — research Pitfall 5 and project memory `feedback_revealsection_stagger.md` mandate this. NO wrapper `<div>` between RevealSection and its staggered children, or the stagger silently degrades to all-at-once.
- `stagger` defaults to `true` in RevealSection but pass it explicitly for clarity.
- The `<h2>` uses `font-display` (Playfair Display) — matches Hero / brand typography.
- Brand-accent token via `var(--color-brand-accent)`, NOT the inline `#FF4500` literal — the Phase 6 sections use the CSS variable (`#FF4500` literal in Hero.tsx is flagged in research as a Phase 7 cleanup, not this phase's concern, but new code should use the token).
- DO NOT add a CTA element at the bottom — research / Open Question 3 settled on no explicit CTA.
- DO NOT translate the divider, the brand-accent value, or anything else not flowing through `t()`.
  </action>

| CI runner → npm registry | `npm ci` pulls 3rd-party packages; lockfile is the integrity boundary |
| CI runner → GitHub Actions Marketplace | `peaceiris/actions-gh-pages@v4` runs with write permissions |
| CI runner → gh-pages branch | Force-push publishes artifact to public CDN |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-05 | Tampering | peaceiris/actions-gh-pages pinning | mitigate | Pin to `@v4` tag (immutable signed release), never `@main` (research anti-pattern) |
| T-08-06 | Elevation of Privilege | PR from fork triggering deploy | mitigate | `if: github.ref == 'refs/heads/main'` guard on deploy step (research anti-pattern §5) |
| T-08-07 | Information Disclosure | secrets in workflow logs | mitigate | Only secret used is auto-provided `${{ secrets.GITHUB_TOKEN }}`; never echo'd; no PAT |
| T-08-08 | Denial of Service | overlapping deploys clobbering each other | mitigate | `concurrency: group: deploy-${{ github.ref }}` + `cancel-in-progress: false` queues second deploy |
| T-08-09 | Tampering | npm supply chain | mitigate | `npm ci` uses lockfile (not `npm install`); production deps already audited through Phases 1–7 |
